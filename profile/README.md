# OpenBot

**Your own bots, for anything.**

Create as many personal AI agents as you need. Give each one a purpose, tools, and tasks to take care of.

Bots can watch for things, use apps and computers, and act on your behalf — while staying persistent over time.

Open source. Self-hostable. Built for everyday life and work.
